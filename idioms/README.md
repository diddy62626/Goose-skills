# idioms

**Idioms** — Migrating from C++/Rust, common pitfalls, reading errors, the pattern catalog.

4 skills. Load any of them as `idioms/<skill>/skill.md`.

- [`goose-common-pitfalls`](idioms/common-pitfalls/skill.md) — Common pitfalls — the gotchas that bite in the first afternoon: > Every pitfall in one list: Euclidean %, width rules and u32+i32 errors, let vs const, for-copy vs for-&x, sequential arrays can't index, frozen variable fields, recursion growable-data rule, reference into temporary, dictionary reference liveness, string literal const, push inside print in recursive cycles, ++ is a statement, no if(n), tinycc limits.
- [`goose-migrating-from-cpp-rust`](idioms/migrating-from-cpp-rust/skill.md) — Migrating from C++ and Rust — pattern by pattern: > The translation table: new/Box::new → locals or push into an array; vector/Vec → T[>..]; string → u8 arrays; virtual functions → enums + case functions; traits → overloads/generics; shared_ptr → slot_pool; Result/? → trailing bool + return E from f; Arc<Mutex> → typed queues; serde → to_bytes; RAII → defer. Plus what does not translate and the nearest shape.
- [`goose-pattern-catalog`](idioms/pattern-catalog/skill.md) — Pattern catalog — the idioms Goose code is written in: > The recurring shapes: builder + push-reference linking, per-iteration scratch buffers, the context struct of references for recursion, nested function parsers, sentinel-based linked lists, enum-tag command tables, case functions as virtual calls, format/hash overloads as the trait replacements, index types for graphs, and pools for non-nesting lifetimes.
- [`goose-reading-errors`](idioms/reading-errors/skill.md) — Reading compiler errors — the two-ends rule: > Goose errors name both ends of the problem. How to read lifetime errors (reference + binding site), shrink errors (holder + store site), generic errors (instantiation + call chain), overload errors (candidates + why each failed), and the decision each message is asking you to make.
