# arrays

**Core concepts** — The array family: fixed/limited/frozen arrays, grow-only and grow-shrink resizables, slices.

5 skills. Load any of them as `arrays/<skill>/skill.md`.

- [`goose-array-family-overview`](arrays/array-family-overview/skill.md) — The array family — eight kinds, one table, which to pick: > Goose has no single array type: T[k] fixed, T[] frozen, T[varint], T[..k]/T[..] limited (inline capacity), T[>..] grow-only resizable (the workhorse), T[>..<] grow-shrink. All store [metadata][elements...] inline, packed, never a pointer to a separate block. Members (.len/.cap/.push/...) and the decision guide.
- [`goose-fixed-limited-frozen-arrays`](arrays/fixed-limited-frozen-arrays/skill.md) — Fixed, limited and frozen arrays — T[k], T[..k], T[..], T[]: > Compile-time sizes (T[k]), inline-capacity arrays that live inside structs and array elements (T[..k], T[..]), and finished frozen data (T[], T[varint]). Fill literals, capacity semantics, sequential arrays, and compile-time size expressions.
- [`goose-grow-only-resizable`](arrays/grow-only-resizable/skill.md) — Grow-only resizable arrays — T[>..], the default container: > T[>..] is Goose's workhorse container: push/append bump the stack, elements never move, references into it stay valid forever, and shrinks are allowed exactly where the compiler proves nothing points into it. Patterns for arenas, builders, scratch buffers, and the shrink rules.
- [`goose-grow-shrink-stacks-queues`](arrays/grow-shrink-stacks-queues/skill.md) — Grow-shrink arrays — T[>..<] for stacks, queues and heaps: > T[>..<] shrinks from anywhere but keeps its interior references out of storage (variables only). Pop/pop_n/resize/clear, the std heap functions, balanced calls that let a recursion share one scratch stack, and the reference rules that make shrink checks cheap.
- [`goose-slices`](arrays/slices/skill.md) — Slices — T[:] views that cannot dangle: > T[:] is a reference plus a count (like span/string_view/&[T]) that every array kind converts to without copying. Slicing syntax including ^k from-the-end, coercion rules, checked roots (cannot outlive the owning variable, cannot survive a shrink), writability, and slices as dictionary keys.
